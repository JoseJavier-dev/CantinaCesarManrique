# Cantina Digital

Aplicación móvil desarrollada como **Proyecto Final de Digitalización de 1.º de Desarrollo de Aplicaciones Multiplataforma (DAM)**.

## 📱 Descripción

Cantina Digital es una propuesta de digitalización para la cantina de un instituto. El objetivo del proyecto es modernizar la gestión de pedidos y mejorar la experiencia de los usuarios mediante una aplicación móvil que permita realizar compras de forma rápida y cómoda, reduciendo las colas y los tiempos de espera.

La aplicación está desarrollada íntegramente en **Java**, utilizando **XML para el diseño de las interfaces**.

## ✨ Funcionalidades principales

- **Realización de pedidos:** Los usuarios pueden consultar los productos disponibles y realizar sus pedidos directamente desde la aplicación.
- **Programación de pedidos:** Posibilidad de seleccionar una hora para recoger los pedidos, ayudando a evitar aglomeraciones y cuellos de botella en la cantina.
- **Sistema de fidelización:** Los usuarios acumulan puntos con cada compra, incentivando el uso de la aplicación y las compras recurrentes.
- **Gestión de promociones y ofertas:** Los gerentes de la cantina pueden añadir y gestionar promociones para los usuarios.
- **Información sobre alérgenos:** Cada producto muestra información sobre sus alérgenos, facilitando la elección de alimentos según las necesidades de cada usuario.

## 🛠️ Tecnologías utilizadas

- **Java:** Lenguaje de programación utilizado para desarrollar la lógica de la aplicación.
- **XML:** Diseño y estructuración de las interfaces gráficas.
- **Android Studio:** Entorno de desarrollo utilizado para la creación de la aplicación.

## 🎯 Objetivo del proyecto

Demostrar cómo la aplicación de soluciones digitales puede mejorar el funcionamiento de un servicio cotidiano dentro de un centro educativo, optimizando la gestión de pedidos, reduciendo los tiempos de espera y ofreciendo nuevas herramientas tanto a los usuarios como a los responsables de la cantina.
